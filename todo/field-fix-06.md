## Problem
Graph Copy could accept incomplete rewiring or recreate pins without explicitly preserving their default values. This can silently change a copied block.

## Scope

Graph Copy checks schema connection responses and refuses implicit conversion/breaking existing links. Missing planned links or wrong node count fail with owned rollback. Capture existing node undo state, refuse unsafe editor contexts and remove implicit structural compilation.

## Default preservation

302c405 restores string/object/text/autogenerated pin defaults using unique name-and-direction matches with exact types, then reads them back after wiring. Ambiguous/missing pins or changed defaults fail through owned rollback. Implementation closed; unbuilt and untested. Unsupported node shapes and the broader round-trip gaps remain open.

## External static library calls

Cross-asset member preflight no longer requires a resolved external static function to be declared on the destination Blueprint. Its external FunctionReference remains intact. Self/unresolved/instance calls retain existing checks. This closes the false destination-member refusal slice of the S3 ED-06 report, not full library-copy runtime acceptance. Unbuilt and untested.

## Undo acquisition before mutation

Graph Copy now requires CanTransact and an outstanding owned undo record before any Modify or node creation. Rollback uses that captured identity instead of adopting the active identity at failure time. Source-confirmed recovery gap closed; unbuilt and untested.
