# Native-tool overlap and investment decisions

Checked 2026-10-17 against the pinned 5.9 development snapshot. The upstream head still matches engine.lock.json. A development snapshot is not a released support guarantee. These are source-interface observations; runtime parity and installation availability remain unverified.

| Area | Observed upstream interface | Decision |
| --- | --- | --- |
| enum authoring | [Create, GetEnumerators, AddEnumerator, RemoveEnumerator, SetDisplayName, MoveEnumerator, IsBitflags, SetBitflags](https://github.com/EpicGames/UnrealEngine/blob/5789fc07f00643fb37f85ede9894cd08f1cebcef/Engine/Plugins/Experimental/Toolsets/EditorToolset/Source/EditorToolset/Private/UserDefinedEnumToolset.h) | Keep 5.8.3 correctness fixes; freeze additional primitive enum authoring until parity of validation, naming/read-back, rollback and compact output is measured. |
| struct authoring | [Create, ListVariables, AddVariable, AddStructVariable, AddObjectVariable, RemoveVariable, RenameVariable, SetVariableDefaultValue](https://github.com/EpicGames/UnrealEngine/blob/5789fc07f00643fb37f85ede9894cd08f1cebcef/Engine/Plugins/Experimental/Toolsets/EditorToolset/Source/EditorToolset/Private/UserDefinedStructToolset.h) | Compare native primitives before expanding TurboMCP struct authoring. Existing field syntax, dependency reporting and safety requirements may remain useful; no equivalence assumed. |
| source control | [GetAssetSourceControlState, LoadAssetRevision, ListAssetRevisions, CreateChangelist](https://github.com/EpicGames/UnrealEngine/blob/5789fc07f00643fb37f85ede9894cd08f1cebcef/Engine/Plugins/Experimental/Toolsets/EditorToolset/Source/EditorToolset/Private/SourceControlToolset.h) | Do not build duplicate history/changelist primitives. Preserve explicit save/checkout outcomes; native presence does not establish provider behavior or write gating parity. |
| widget animation | [CreateWidgetAnimation, ListWidgetAnimations, FindWidgetAnimation, RenameWidgetAnimation, SetWidgetAnimationLength, RemoveWidgetAnimation, AddWidgetToAnimation, GetWidgetAnimationBindings](https://github.com/EpicGames/UnrealEngine/blob/5789fc07f00643fb37f85ede9894cd08f1cebcef/Engine/Plugins/Experimental/Toolsets/WidgetAnimationToolset/Source/WidgetAnimationToolset/Private/WidgetAnimationToolset.h) | Defer broad animation authoring. Measure native lifecycle/binding coverage before considering a thin workflow adapter; these names do not prove arbitrary track/key editing support. |
| MCP stdio bridge | [stdio bridge, upstream reconnect, tool-list change notification, explicit mcp-json path](https://github.com/EpicGames/UnrealEngine/blob/5789fc07f00643fb37f85ede9894cd08f1cebcef/Engine/Plugins/Experimental/ModelContextProtocol/Extras/Proxy/README.md) | Do not develop a competing proxy. Assess the native bridge for the harness; preserve client unknown-mutation-outcome semantics and never assume reconnect authorizes replay. |

The known compatibility work remains registry identity removal, dependency discovery, media content blocks/structured references, explicit JSON null and child-actor edit restrictions. See [engine compatibility](../engine-compatibility.md).

Refresh only when starting a relevant task or approving new overlapping scope. Record old/new SHA and relevant API diff. If the target changed, reassess that affected decision; do not restart the whole roadmap or implement speculative work. The 5.8.3 baseline stays pinned.
