# TurboMCP

Experimental Unreal Editor tools for Blueprint graphs, materials, widgets, captures, levels and actors. This development snapshot is **not a finished release**.

Supported development baseline: Windows, Unreal Engine 5.8.3 source revision 396c9f059903aed5fec78ecd3d437a40c6415368. Unreal 5.9, Launcher builds and other platforms are not certified by this snapshot.

The installable plugin is in Plugins/TurboMCP. See [installation](docs/installation.md) and the [declared tool reference](docs/tools.md). Source is licensed under MPL-2.0; retain the license and source notices when distributing.

No engine source or development credentials are included. Generated binaries are distributed separately when a release is validated. Declared tools and descriptions are not a claim that all acceptance tests pass.
