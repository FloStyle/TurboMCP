# Tasks

Written copy of the DSH task board for this project, one Markdown file per card.

- Scope: `backlog`, `todo` and `running` cards (running cards are recorded as `todo`).
- Source of truth: the DSH task board, not this folder.
- `INDEX.md` lists every card by status and priority.
- `snapshot.json` holds the same cards as machine-readable JSON.
- `export_task_board.ps1` regenerates this folder from the board ledger.
